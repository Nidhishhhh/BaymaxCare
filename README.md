# BaymaxCare 🩺🤖

**BaymaxCare** is a telehealth, in-home senior companion, and real-time remote patient monitoring system built for elderly care, doctors, and family guardians.

---

## 🌟 Key Features

### 👨‍⚕️ Doctor Dashboard (`dashboard-doctor.html`)
- **Patient Profile Management**: Switch across multiple patient profiles with distinct clinical charts, diagnoses, and vitals baseline.
- **Smart Intake & Medical Records Auto-Fill**: Upload PDF, Word document, or photo medical reports to automatically parse patient demographics, conditions, medications, and caregiver details via Gemini multimodal API.
- **Real-Time Clinical Vitals**: Monitor live Heart Rate (HR), SpO2, Body Temperature, Respiration Rate, PTT pulse transit time, and PPG waveforms.
- **Incident & Emergency Response**: Real-time fall detection verification and automated alert notifications.
- **Maximized Live Camera**: Live video feed streaming from the in-home companion device with theater mode.
- **Guardian Credential Generation**: Auto-generates unique, secure portal credentials for family guardians.

### 🛡️ Guardian Dashboard (`dashboard-guardian.html`)
- **Real-Time In-Home Companion**: Check in on elderly family members anytime with live video feed.
- **Voice Companion**: Interactive simulated audio check-ins and symptom reporting.
- **Medication Schedule & Adherence**: Daily dose tracking with morning/evening status and adherence history.
- **Clean Consumer UI**: Hardcoded companion camera stream with no confusing networking configurations.

### 🍓 Companion Camera Server (`rasberry pi codes/cam_server.py`)
- Lightweight Flask/Picamera stream server running directly on Raspberry Pi with live MJPEG streaming, on-demand activation, and snapshot capabilities.

### ⚡ FastAPI & PostgreSQL Backend (`server.py`)
- REST API and WebSocket architecture backed by PostgreSQL (Aiven Cloud).
- Endpoints for doctor/guardian authentication, patient roster management, medication records, appointments, and live vitals broadcasting.

## 🚀 Quick Start

### 1. Requirements
- Python 3.10+
- Modern Web Browser (Chrome, Edge, Firefox, Safari)

### 2. Setup Virtual Environment & Dependencies
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install fastapi uvicorn sqlalchemy psycopg2-binary google-genai pydantic python-dotenv
```

### 3. Environment Configuration
Copy `.env.example` to `.env` and fill in your keys:
```bash
cp .env.example .env
```

### 4. Database Setup & Server Launch
```bash
# Seed initial clinical data (optional):
python seed_db.py

# Launch FastAPI backend:
python server.py
# Or double-click run_server.bat on Windows
```

Backend will run on `http://127.0.0.1:8000`.

### 5. Open Dashboards
Open `login.html` in your browser to sign in:
- **Doctor Portal**: Select physician credentials or use 1-click test credentials.
- **Guardian Portal**: Sign in with credentials generated by the patient's attending doctor.

## 🔒 Privacy & Safety
- Remote video feed only streams upon authorized live request.
- Fall verification protocol waits 30 seconds before escalating to emergency contacts.
- Strict data separation between clinical doctor administration and family guardian portals.
